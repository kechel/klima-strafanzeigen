# Parlamentarischer Bypass — Kleine Anfrage über eine:n MdL

Zweck: Der Bürger→Rechnungshof-Kanal ist einseitig (kein Rückkanal). Eine **Kleine
Anfrage** über eine:n Landtagsabgeordnete:n zwingt die Landesregierung dagegen zu einer
**öffentlichen, datierten, zitierbaren** Antwort — der eigentliche Hebel, um die Frage
„wer trägt die Ausweispflicht?" aktenkundig zu machen.

## Drei versandfertige Bündel

| Ordner | Inhalt |
|---|---|
| `bw/` | Baden-Württemberg (Landtag): `mailtext.md` (Anschreiben an MdL = E-Mail-Body), `kleine-anfrage-bw.pdf` (Anhang), `kleine-anfrage-bw.md` (editierbare Quelle), `versand.md` |
| `nrw/` | Nordrhein-Westfalen (Landtag): analog |
| `bund-linke/` | **Bundestag, Fraktion Die Linke — wärmste Spur:** die einbringenden MdB von BT-Drs. 21/1783 (Fahl, Pantisano, Bauer) haben genau dieses Thema bearbeitet, aber die Haushaltsfrage nicht gestellt. Anschreiben + Bundestags-Kleine-Anfrage zur Haushaltsdimension (Bundeshaushalt, §§ 7/8/11/17 BHO, Bund-Länder-Lücke). |

**Hinweis Parteien:** Die Linke ist **nicht** im BW-Landtag (4,4 %, 2026) und kann dort
keine Anfrage stellen — wohl aber im **Bundestag** (dort der natürliche Weg). Im BW-Landtag
regieren Grüne+CDU; Opposition = SPD, AfD (AfD ausgeschlossen). Nur sitzende Abgeordnete
haben Initiativrecht.

**So verschicken:** Eine:n MdL wählen → `mailtext.md` als E-Mail-Text, die
`kleine-anfrage-*.pdf` als Anhang, Link auf co2-entnahme.info. Die `.md`-Fassung der
Anfrage mitschicken/anbieten, falls das Büro den Text anpassen will.

## Adressatenwahl

Am wirkungsvollsten: **haushalts- oder klimapolitische:r Sprecher:in** einer Fraktion
bzw. Mitglied des **Finanz- oder Umweltausschusses**.
- **BW:** Grüne führen die Regierung (Anfrage aus der Regierungsfraktion wirkt intern,
  ist aber gegenüber dem eigenen Finanzressort heikel); pointierter aus der Opposition
  (SPD, FDP).
- **NRW:** CDU/Grüne regieren; pointierte Anfrage eher aus der Opposition (SPD).
Beides möglich — die Anschreiben sind so gehalten, dass sie für beide Rollen passen.

## Form

- **BW:** Das Instrument heißt formal meist **„Antrag"** (mit Berichtsteil: „Die
  Landesregierung wird ersucht zu berichten …"). Das MdL-Büro bringt die Endform.
- **NRW:** **„Kleine Anfrage"** (schriftliche Frage an die Landesregierung, § 91 GO
  Landtag NRW). Auch hier kennt das Büro die genaue Vorlage.

Die Fragen sind so formuliert, dass sie sich direkt übernehmen lassen.
